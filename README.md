# ml-supervised-learning-project


## 📌 Project Title
Supervised Learning Model using Scikit-learn

## 📖 Description
This project is a Machine Learning model built using Python and Scikit-learn.
The goal of this project is to train a supervised learning model and make predictions on dataset.

This project was created using Google Colab and uploaded to GitHub for practice and internship preparation.

## 🚀 Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## 📂 Project Files
- Supervised_Learning.ipynb → Main notebook
- titanic→ Dataset used
- README.md → Project description

## ⚙️ Algorithm Used
- Linear Regression / Logistic Regression / Decision Tree / KNN / GaussNB /SVC


## ▶️ How to Run
1. Open the notebook in Google Colab
2. Run all cells step by step
3. Model will train and show output
